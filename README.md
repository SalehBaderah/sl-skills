# Skills

Reusable agent skills for creative and development workflows.

- [Website Walkthrough](website-walkthrough/README.md) — cinematic, mockup-style website demo videos from uploaded recordings or live browser capture. Includes installation, usage examples, and rendering tools.

Install for Codex in the current project:

```bash
npx skills add https://github.com/Sl-15-dev/sl-skills/tree/work --skill website-walkthrough --agent codex
```

Add `--global` for a personal installation. See the [setup and usage guide](website-walkthrough/README.md) for Python, FFmpeg, optional browser capture, motion controls, and other supported agents.
