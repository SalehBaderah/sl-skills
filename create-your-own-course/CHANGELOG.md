# Changelog

## 1.0.0 — 2026-11-17

- Initial public release: plan-first course design, incremental modules, teaching and review loop, progress tracking, optional templates, and a paste-ready `PROMPT.md`.
- Courses default to `courses/<course-slug>/` at the workspace root, never inside the installed skill folder.
- Content creation is the core task: explicit standards for theory lessons and practical work, a study-ready depth bar, separate answer keys, and a richer module template.
- Added `scripts/check_prompt_sync.py` to keep `PROMPT.md` aligned with `SKILL.md`.
